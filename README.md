# Kênh giao file cắt laser – Cơ Khí Minh Kiên

Nhánh này chỉ chứa gói file cắt (.zzx) theo số đơn DD-MM-YY_NNN.zip. Không chứa bản vẽ, tên khách.

- Máy 2: chạy 1 lần `CAI_DAT_MAY_2.bat` → mỗi 5 phút tự lấy gói mới, giải nén vào `C:\DonCat\<số đơn>\`.
- Điện thoại: bấm link `https://raw.githubusercontent.com/daokien04021989-arch/minh-kien-video/don-cat/<số đơn>.zip` là tải về.
